# ساعت دسکتاپی — نسخه اندروید ۶ (API 23)

نسخه اندروید برنامه ویندوزی Desktop Clock Jalali.

## امکانات
- ساعت دیجیتال و آنالوگ با تاریخ شمسی و نام روز هفته
- ارقام فارسی، فرمت ۲۴ ساعته / ۱۲ ساعته، نمایش یا عدم نمایش ثانیه
- ۶ تم رنگی
- آلارم با تکرار روزهای هفته یا یک‌بار (با AlarmManager دقیق)
- آلارم حتی بعد از ری‌استارت گوشی (BootReceiver)
- پخش صدای آلارم و ویبره، نمایش روی صفحه قفل، توقف خودکار بعد از ۶۰ ثانیه
- گفتن ساعت (TTS) هنگام آلارم و هر ساعت (وقتی برنامه باز است)

## کارهایی که در نسخه اندروید نیست
- پنهان شدن با نزدیک شدن موس و حالت شفاف روی دسکتاپ (مفهوم دسکتاپ ندارد)
- صدای تیک‌تاک و زنگ ساعت (Synth)
- کلیدهای میانبر و شروع خودکار ویندوز
- ساعت شناور روی صفحه (به‌جای آن اپلیکیشن کامل است)

## ساخت
1. پوشه `DesktopClockAndroid` را در Android Studio باز کنید (Open).
2. با دکمه Run روی گوشی یا شبیه‌ساز با اندروید ۶ یا بالاتر اجرا کنید.
3. برای APK: Build > Build APK(s).
